# 전체 홈페이지 v55 이지모바일 + 조이텔 업데이트

기존 전체 사업자 홈페이지 v55 프로젝트용 교체 파일입니다.

## 적용 방법
압축 안의 홈페이지-v55 폴더가 아니라 내부 파일들을 기존 저장소 루트에 반영하세요.
- mvno_combined_edge_v55.py: 기존 파일 교체
- mvno_easy.py: 새 파일 추가 (크롤러와 같은 폴더)
- .github/workflows/mvno.yml: 기존 경로에 교체 (beautifulsoup4 설치 추가)
- requirements.txt: 의존성 목록. 로컬은 pip install -r requirements.txt

기존 템플릿, mvno_history.py, mvno_notify.py, history 폴더는 유지하세요.
GitHub Secrets와 실행 시간, 기존 사업자 수집 순서는 원본 v55 설정을 유지합니다.
전체 홈페이지 프로젝트입니다. 조이텔 T001~T030 탐색을 추가했습니다. 동일한 목록이 반복되는 코드는 한 번만 반영합니다. 선불은 제외합니다.

## 변경점
이지모바일 KT/LG를 다시 수집합니다. 동적 #bill-list 로딩을 기다리고 각 요금제 행의 이름/데이터/음성/문자/할인 월요금/할인 기간/이후 요금을 추출합니다. 정가와 할인 월요금을 구분하고 사은품 행은 제외합니다.
실패하면 기존 수집 오류 시트에 표시하고, 해당 사업자는 변동 비교에서 제외합니다.

## 검증과 제한
사용자 제공 화면 HTML 기준 KT 49건, LG 50건(합계 99건) 추출 및 보고서 생성 검증.
실시간 접속과 페이지 이동은 개발 환경의 연결 시간 초과로 검증하지 못했습니다.
기간 문구가 없는 10건은 기간/이후 요금을 빈칸으로 유지합니다. 데이터 쉐어링의 원문 데이터 공란도 유지합니다. 상세에만 있는 QoS는 추측하지 않습니다.

조이텔: 8개월 차부터는 할인 기간 7개월로 기록합니다. 평생 할인은 할인 기간/이후 요금을 빈칸으로 유지합니다. 수집 실패는 수집 오류 시트에 표시하고 변동 비교에서 제외합니다. 기존 TYPE_CODES(T001~T030)를 공유합니다. 실시간 30개 페이지 전체 수집은 이 환경에서 검증하지 못했습니다.

## 쉐이크모바일 추가
추가 파일 mvno_shake.py도 크롤러와 같은 폴더에 업로드하세요. 기존 이지모바일 수정과 조이텔 T001~T030 탐색은 포함되어 있습니다.
공개 /M2Mobile/getTG01NETDIV에서 탭을 조회하고 /M2Mobile/getTG01ByLtediv에 각 탭 코드를 POST합니다. 현재 6개 탭을 조회하며 신규 탭도 목록에 나오면 자동 포함됩니다. 같은 gdcd는 한 번만 저장하고 가격 정보가 서로 다르면 오류로 처리합니다.
실제 API 검증: 한정특가 7, 평생혜택 42, 반값세일 28, Npay플러스 4, 이투스 12, 데이터쉐어링 1 = 총 94건. 개수는 향후 변동될 수 있습니다.
월 요금은 tt_AMT, 할인 기간은 promo_MM, 종료 요금은 사이트 코드와 동일한 amt - parseInt(life_TIME_DISCOUNT * 1.1)입니다. promo_MM=0이면 기간/종료 요금은 빈칸입니다. 망은 사이트 카드와 동일하게 KT로 기록합니다.
실제 JSON 응답 파싱과 엑셀 생성은 검증했습니다. Windows Edge와 GitHub Actions에서의 전체 실행은 검증하지 못했습니다.
